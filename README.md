# 🧠 MEB Yönetmelik Asistanı – LLaMA 3.3 70B Tabanlı Yapay Zekâ Sistemi

## 📌 Proje Hakkında

Bu proje, Millî Eğitim Bakanlığı (MEB) yönetmelik metinlerini analiz eden ve kullanıcıların doğal dilde sorduğu sorulara yapay zekâ destekli yanıtlar üreten bir asistandır. Sistem, büyük dil modeli (LLM) kullanarak mevzuat bilgilerini daha erişilebilir hale getirmeyi amaçlamaktadır.

## 🎯 Proje Amacı

- MEB yönetmeliklerinin hızlı ve anlaşılır şekilde sorgulanabilmesini sağlamak
- Kullanıcıların doğal dil ile soru sorabilmesini mümkün kılmak
- Büyük dil modeli (LLM) ile mevzuat tabanlı akıllı cevap üretmek
- Eğitim ve araştırma süreçlerini kolaylaştırmak

## ⚙️ Kullanılan Teknolojiler

- Python
- Streamlit
- Yapay Zekâ / NLP
- Meta LLaMA 3.3 70B Versatile (Large Language Model)

## 🤖 Model Mimarisi

Bu projede LLaMA 3.3 70B Versatile büyük dil modeli kullanılmıştır.

Sistem şu şekilde çalışır:

1. Kullanıcı sorusu alınır
2. Soru doğal dil işleme sürecinden geçirilir
3. LLaMA 3.3 70B modeli üzerinden bağlam analiz edilir
4. MEB yönetmelik verileri ile ilişkilendirilerek yanıt üretilir
5. Sonuç Streamlit arayüzü üzerinden kullanıcıya sunulur

## 🧩 Özellikler

- 📄 Yönetmelik metinlerini analiz edebilme
- 💬 Doğal dil ile soru-cevap sistemi
- ⚡ Gerçek zamanlı yapay zekâ yanıtları
- 🌐 Streamlit tabanlı web arayüzü
- 🧠 LLaMA 3.3 70B ile yüksek kaliteli dil anlama
